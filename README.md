# Visualization and Analysis of Earthquake Data (Observable)

## 👥 Team
Edison Lu, Yanting Hu, Shuxin Zhang, Braden Sams

An interactive data visualization project built in **Observable** to explore global earthquake patterns from **Jan 2022 to Jan 2024** using **USGS earthquake data**. The notebook presents multiple linked views (maps + charts) to help users understand the **geographic distribution**, **depth/magnitude characteristics**, and **temporal trends** of seismic activity.

## 🚀 Live Demo (Observable)
https://observablehq.com/d/29fb341e7fc8cf65

## 🎯 Project Motivation
Earthquakes cause substantial loss of life and economic damage worldwide. By visualizing earthquake events, we aim to help audiences (general public and decision-makers in earthquake-prone regions) better understand seismic risk patterns and how they relate to tectonic plate boundaries.

## ❓ Key Questions
1. **Where do earthquakes occur globally?**
2. **How do earthquake depth and magnitude distribute across regions?** Which areas see deep and large earthquakes more often?
3. **What is the magnitude distribution?** Which magnitude range occurs most frequently?
4. **How do earthquake magnitudes differ between 2022 and 2023?**

## 🔍 What’s in the Notebook
- **Global distribution map (2022–2024):** Earthquake points align with major plate boundaries (e.g., Ring of Fire, Alpide belt, Mid-Atlantic Ridge).
- **Depth & magnitude view:** Point size encodes magnitude to highlight where strong events concentrate.
- **Magnitude distribution + daily trends:** Shows typical magnitude ranges and notable peaks in seismic activity.
- **Year comparison (2022 vs 2023):** Compares monthly average magnitude trends between years.

## 📊 Data Source
- **USGS Earthquake Catalog** (Jan 2022 – Jan 2024)

## 🛠 Tech Stack
- **Observable** (JavaScript / D3-style interactive visualization)
